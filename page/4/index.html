人生苦短，我用 conda

June 28, 2023 · 2 min read

以前要嘗試 Python 的各種函式庫時，會用 virtualenv 或 docker 來產生專用的獨立環境。 但 Python 版本更新也算快，若想用特定 Python 版本執行，還需再搭配 pyenv 來確認運行環境，這些套疊讓環境設定變得更複雜。

現在已有 miniconda 工具，只要用 brew 就可以安裝

brew install --cask miniconda

使用體驗相當好，節省了許多學習與設定的時間，也可以安心的去嘗試各種函式庫。
